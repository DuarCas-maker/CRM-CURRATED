Configuración cambia por publicación explícita de hash/generación de servicio; fuente real/acreditación de contexto y sus rotaciones aún pendientes de integración posterior.

Un check correcto deja candidato/bloqueado. Confirmación humana independiente consume evidencia válida y marca verified, con recibo/auditoría atómicos; jamás active. Reemplazar/revocar verified conserva la revisión/historia. GET marca stale si caduca la evidencia o cambian configuración/actor/cuenta. Replay idéntico devuelve recibo histórico, no renueva evidencia o aprobación efectiva. UI C1 sin controles nuevos y flags de ejecución false.
