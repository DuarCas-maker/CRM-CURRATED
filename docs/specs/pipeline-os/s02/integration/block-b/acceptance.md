# Criterios de aceptación B

Criterios de aceptación: resultados locales B1 en [su evidencia](b1-verification.md) y B2 en [b2-verification.md](b2-verification.md). Visual/teclado, build completo y contención PostgreSQL independiente no se dan por aceptados. Datos ficticios: dos marcas, al menos dos cuentas, cinco roles y contextos operativos separados, anon/AAL1/inactivo y notificación válida.
