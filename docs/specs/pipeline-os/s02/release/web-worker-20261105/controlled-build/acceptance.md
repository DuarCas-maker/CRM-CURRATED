| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| AC01 | Dado el archivo sellado, al trasladarlo y extraerlo en carpeta nueva, coinciden SHA256, inventario776 y hashes de fuentes; cualquier discrepancia bloquea.                                                          | hash original/destino, listado/rutas seguras y cotejo por archivo                          |

Casos negativos adicionales: nombre builder/tag existente → detener sin sobrescribir; plugin ausente → detener sin instalar; base distinta entre imágenes → revisar; web falla → no construir worker; Docker pierde límites/servicio se degrada → cancelar; shell/pipeline oculta error → no aceptar; limpiar cachés/imágenes ajenas o ampliar memoria automáticamente → prohibido.
