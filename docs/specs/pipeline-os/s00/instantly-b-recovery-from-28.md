## Reintentos, conciliación y condiciones de parada

- Solo lecturas con red/timeout/429/5xx: como máximo un retry por operación, dentro de R3 global, backoff≥5s y Retry-After≤60s. 401/402/403/404/otros4xx permanentes, redirect/schema/identidad fallan sin retry ciego.
- Ningún POST de alta o PATCH de A se repite. Respuesta incierta se concilia con POST leads/list filtrado por campaña+email para alta (limit100, exactamente una fila propia y sin cursor) o GET A para update. Cero filas, skip explícito, múltiples candidatos, identidad/marcadores inválidos o reserva agotada→detener, nunca reemplazar contacto/nonce. No buscar globalmente otra campaña.
- Cada efecto exige preflight completado, al menos1 slot R disponible, H2 intactos, suficientes N para el resto más largo y saldo total para ese resto+1 conciliación+2 emergencia. Conciliación puede reintentar solo lectura transitoria si queda R, sin repetir write. Reserva/contador se guarda antes de HTTP; error de persistencia no se convierte en saldo libre ni retry de disco.
- Audiencia: limit1/distinct_contacts=false, cursor del último ID, máximo3 páginas; solo A/B sin duplicados/terceros. Tercera página solo permite fin vacío válido; cursor repetido/fila extra/cursor sin fin detiene, sin cuarta página. Instantánea de cada lead incluye campos ajenos a s00_hold para detectar cambios de B o drift de A.
- Emergencia solo tras intento de efecto de esta fase y campaña propia ya verificada, ante fallo elegible: POST pause una vez y GET propio una vez, sin signal para poder cerrar tras cancelación. Guarda de emergencia acredita identidad/workspace/status2, no recuperación completa. Auth/pago/permisos/identidad/tenant ajenos o disco incierto no disparan otra escritura; reportar pausa no comprobada si corresponde.
- Abort antes de reservar no consume llamada; durante HTTP conserva intento. Al terminar, status failed o completed e historial completo; crash/IN_FLIGHT requiere revisión separada, nunca reanudar por ejecutar de nuevo o restaurar v6. No borrar leads/campaña como rollback, activar o enviar para comprobar funcionamiento.
