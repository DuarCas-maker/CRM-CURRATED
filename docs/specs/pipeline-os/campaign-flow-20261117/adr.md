# ADR — Reutilizar las secuencias existentes

Decisión: una campaña, una cuenta y cuatro pasos congelados. El motor ya avanza enrollment.step al confirmar Gmail y detiene secuencias con respuestas y bajas. Evita cinco campañas físicas y un segundo scheduler. Añadir exclusivamente calendario civil, consentimiento de verificación y experiencia simplificada. El registro tipado limita el cambio a campañas nuevas. Los grupos anteriores permanecen compatibles.

El usuario confirmó intervalos 2/3/3/5, asesor existente, mismo remitente y cuatro plantillas. Se preparan textos neutros editables; no se inventan ofertas ni promesas financieras. Las campañas existentes no reciben seguimientos retroactivos.
