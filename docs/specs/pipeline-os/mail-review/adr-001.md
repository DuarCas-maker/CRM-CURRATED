# MR-ADR01 — revisión durable y aprobación atómica

Aceptada para este incremento local. Una sucesión de comandos independientes (offer/create_task/activity) puede quedar incompleta y duplicarse. Se elige una revisión durable y una RPC transaccional específica. Reutiliza los modelos de negocio y evidencia existentes; agrega solo revisión y requisitos individuales. Alternativa: automatización completa de correo, descartada por el control humano y consumo bajo demanda confirmados. Se reutiliza el proveedor/modelo/clave de extracción actuales y su contabilidad, sin migrar claves ni introducir dependencias.
