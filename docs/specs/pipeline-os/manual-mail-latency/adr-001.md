# ADR-001: vía manual dentro del worker

Decisión: dispatcher independiente y acotado por cuenta, reutilizando sender, transporte y controles B2. La base sigue siendo la autoridad entre réplicas. Evita bloquear envíos detrás de sincronizaciones sin añadir otro proveedor o enviar desde una petición web que puede terminar antes del resultado.

Alternativas: reducir solo el sleep no resuelve un job largo; un envío directo desde la ruta HTTP complica incertidumbre y continuidad; varios workers generales aumentan carreras y tráfico ajeno. La vía manual necesita SQL compatible y activación explícita. Campañas permanecen fuera de esta aceleración.
