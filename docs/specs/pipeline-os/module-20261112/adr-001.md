# ADR-001: módulo aditivo sobre el CRM

2026-11-12 · aceptada por la aclaración 2 del usuario.

Contexto: se pide fidelidad al mockup y conservar los módulos actuales, particularmente Conversaciones. Reescribir CRM mezclaría alcance y arriesgaría correo/permisos ya probados. Copiar el HTML mantendría acciones simuladas y datos desactualizados.

Decisión: rutas y CSS aislados; proyecciones operacionales nuevas; APIs de acciones y componentes existentes reutilizados. Un enlace adicional es la única modificación prevista en el shell original. No nueva base, proveedor o dependencia. Una lectura de catálogo necesita permiso de sesión/MFA y RLS, igual que el CRM.

Consecuencias: se conserva una fuente de verdad; quedan dos entradas de navegación durante la transición. Las capacidades de los proveedores siguen dependiendo de su configuración actual. El cambio se retira eliminando el enlace y las rutas nuevas, sin migrar datos. No autoriza operación real ni publicación.
