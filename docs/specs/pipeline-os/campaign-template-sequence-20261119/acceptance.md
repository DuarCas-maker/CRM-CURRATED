# Aceptación

- Elegir remitente A muestra su firma Gmail; elegir B nunca conserva A durante carga/error. Ningún texto de Daniel procede del preset.
- Cada paso editable permite asunto/cuerpo y vista previa. Guardar y volver a crear campaña devuelve exactamente esos cuatro pasos, con intervalos fijos.
- Duplicar preserva los recordatorios. La firma automática corresponde al remitente de la nueva campaña.
- Sesión anónima/MFA insuficiente/cuenta ajena/preparación vieja/ruta incompatible se rechazan antes del proveedor. Revocación durante espera impide wire.
- Firma HTML maliciosa permanece en iframe sandbox con CSP sin red/scripts. Falla de consulta visible y reintentable; no sustituir por otra identidad.
- SQL conserva historial y campañas activas byte a byte; reversa no pisa una edición posterior. Pruebas locales ficticias no llaman proveedores.
